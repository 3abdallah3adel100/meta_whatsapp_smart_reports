# إصلاح حساب Overall Daily Budget و Overall Live Budget

## السبب المكتشف
الكود الأصلي كان يشترط أن تكون الحملة أو المجموعة فعّالة وأن يكون لها صرف فعلي اليوم قبل إضافة Daily Budget. لاحقاً تغير المنطق إلى إضافة كل ميزانية لها إعلان Active حتى لو لم تنفق اليوم؛ مما قد يرفع الإجمالي. كما كان تقرير الإغلاق يجمع صرف الوحدات المتوقفة على مستوى campaign/adset، ولا يتعرف بدقة على إعلان توقف داخل Ad Set ما زال يعمل.

## القاعدة النهائية
1. Overall Live Budget = مجموع الميزانيات اليومية للـ CBO campaign أو ABO adset بحد أقصى مرة واحدة لكل budget owner، بشرط ACTIVE على كل المستويات ووجود Ad ACTIVE وصرف فعلي اليوم (نفس شرط النسخة الأصلية).
2. Stopped Spend Today = الصرف الفعلي لمالكي الميزانية (CBO Campaign أو ABO Ad Set) **الذين لا تُحتسب لهم ميزانية Live**. إذا ظل الـAd Set/الـCampaign شغالًا بميزانية Live فلا نضيف فوقها صرف أي إعلان متوقف داخله، لأن الصرف داخل ميزانية نفس المالك. يُحسب الصرف مرة واحدة لكل ad_id، ولا تُضاف الميزانية اليومية لكيان متوقف.
3. Overall Daily Budget = Overall Live Budget + Stopped Spend Today.
4. لا يجوز جمع Spend على مستوى Campaign وAd Set وAd لنفس الإعلان؛ نستخرج كل spend من طلب Insights واحد بمستوى ad ونجمّع التجميعات إحصائياً محلياً.
5. الميزانية Lifetime لا تعامل كميزانية Daily، ولا يضاف ABO تحت CBO مالك للميزانية.
6. Balance Coverage يعتمد على Live فقط لأنه يعكس الصرف التشغيلي القادم.

## التعديلات
- `budget_policy.py`: أُضيفت الدالة `allocation_budget_breakdown` لتطبيق القواعد السابقة؛ الدالة القديمة `closing_budgets` بقيت كما هي حتى لا يتغير تقرير أرقام الواتساب.
- `allocation_meta.py`: يستخدم Spend على مستوى الإعلان ويسترجع Metadata الناقصة عند الضرورة، ويتوقف بخطأ واضح بدل حساب بيانات غامضة أو مكررة. وتُكتب خلاصة `BUDGET AUDIT` لكل حساب في GitHub Actions logs.
- اختبارات التوافق والحالات الصعبة ضمن tests.

## نتيجة الاختبارات المحلية
تم تشغيل 51 اختبار Python بنجاح. هذه اختبارات منطقية ببيانات افتراضية وليست تأكيداً مباشراً للأرقام الحقيقية من Meta.

## طريقة الرفع
ارفع `allocation_meta.py` و`budget_policy.py` فقط من الملف الذي اسمه `CHANGED_FILES.zip` داخل الريبو على فرع main، أو استخدم الملف الكامل. GitHub متصل من ChatGPT للقراءة فقط ولا يمكنني تنفيذ Push بهذا الاتصال.

## مثال
Ad Set Live ميزانيته اليومية 1000 جنيه، إعلان Live صرف 30 جنيه وإعلان متوقف صرف 70: Live = 1000، Overall Daily = 1000، Stopped Spend Today = 0. لو الـAd Set كله اتقفل بعد ما صرف 100 جنيه: Live = 0، Overall Daily = 100. ولو Ad Set تاني مستقل ومتوقف صرف 150 جنيه بينما الأول شغال: Overall Daily = 1150.

## تنبيه بشأن تجربة التحديث
لأن Meta قد تُرجع بيانات مؤرشفة/ناقصة في بعض الحسابات، إذا تعذر تحديد حالة إعلان صرف اليوم في مجموعة وحملة لا تزالان Active فسيُوقف إرسال إجمالي غير مؤكد بدلاً من عرض رقم مضلل. راجع سطر BUDGET AUDIT لكل حساب لتحديد أي فرق.
